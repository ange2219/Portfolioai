AI FASHION VISUALS — PORTFOLIO

CONTENU
- index.html : site portfolio autonome, responsive, sans installation.
- images/ : images illustratives extraites de l'ancien mockup.

IMPORTANT AVANT ENVOI
Les images actuelles sont des exemples de mise en page, pas tes réalisations. Remplace-les par tes propres images.

COMMENT AJOUTER TES VRAIES IMAGES
1. Ouvre index.html dans un éditeur de texte ou un éditeur de code.
2. Dans le bloc JavaScript qui commence par const categories=, chaque catégorie contient cover et models.
3. Pour chaque modèle : main = image principale du mannequin ; views = exactement 3 images générées ; captions = leurs légendes (Front view, Back view, Lifestyle view, etc.).
4. Mets tes fichiers dans le dossier images/ et remplace les chemins d'image par exemple images/robe-face.jpg.
5. Remplace YOUR_EMAIL@example.com par ton adresse professionnelle.

FONCTIONNEMENT
- Cliquer sur une catégorie ouvre sa galerie.
- Chaque modèle affiche une image principale et trois vues générées.
- Survol des vignettes : aperçu/effet visuel ; clic : agrandissement.
- Sur téléphone, toucher une image l'agrandit.

Le site est en anglais pour une candidature internationale.
